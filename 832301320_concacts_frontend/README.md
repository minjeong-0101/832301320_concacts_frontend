# Contact Manager - Frontend

This is the frontend part of a contact management application, built with HTML, CSS, JavaScript, and Vue.js.

## Features

- Add new contacts
- Edit existing contacts
- Delete contacts
- View all contacts

## Setup and Run

1. Clone this repository
2. Open `src/index.html` in a web browser
3. Make sure the backend server is running (see backend README)

## Dependencies

- Vue.js (loaded via CDN)
